## 洛杉矶、香港、东京，节点怎么选

**洛杉矶**：离国内物理距离最远，但 CN2 GIA 线路优化后延迟反而比很多亚洲节点稳。IP 段相对干净，适合需要美国 IP 的场景。

**香港**：物理距离近，延迟天然低。但香港节点库存经常告罄，价格也比洛杉矶贵。有货的时候值得抢。

**东京**：走软银或 CN2 线路，对联通用户友好。如果你主要是联通宽带，东京节点可以优先考虑。

我用的是洛杉矶，主要因为稳定性和 IP 质量，延迟在 150ms 左右，日常用完全够。

## 常见问题

### DMIT 支持退款吗？

官网提供退款保障，具体条款在购买页面有说明。我没用过退款，但看过几个用户反馈，正常申请流程走下来没什么问题。

### DMIT 的 VPS 可以用来建站吗？

可以。EB 系列性价比足够，跑 WordPress、静态站、小型应用都没问题。如果是跑高并发或者数据库密集型应用，建议选 Mini 以上配置。

### 流量用完了怎么办？

DMIT 的处理方式是限速，不是直接断线。超出后带宽会降到一个较低的值，不会突然失联。这点我觉得比较人性化。

### DMIT 支持哪些支付方式？

支持支付宝、PayPal、信用卡等主流方式，国内用户付款没有障碍。

### EB 系列和 Pro 系列能随时升级吗？

可以在控制面板内升级套餐，差价按剩余周期折算。我从 EB Starter 升到 Pro Starter 就是这么操作的，没有额外手续费。

### 香港和东京节点为什么比洛杉矶贵？

亚洲节点的带宽成本本身更高，加上 CN2 GIA 线路资源有限，定价自然上去了。如果预算有限，洛杉矶 Pro 系列是性价比最高的选择。
